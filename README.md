# 🤖 SalesCopilot IA — Assistente de Vendas

## 📌 Sobre o projeto

Projeto desenvolvido para o desafio da DIO, com o objetivo de criar um assistente de IA para ajudar vendedores no atendimento em lojas.

A ideia é facilitar a comunicação com clientes, recomendar produtos e melhorar o processo de vendas.

## 🎯 Objetivo

Criar um assistente que ajude profissionais de vendas a responder dúvidas, apresentar produtos e organizar atendimentos de forma simples e rápida.

## 🛠️ Ferramentas utilizadas

- ChatGPT
- Engenharia de Prompts
- GitHub

## 🚀 Funcionalidades

- Atendimento e identificação das necessidades do cliente.
- Sugestões de produtos.
- Criação de pitches de vendas.
- Respostas a objeções.
- Mensagens de follow-up.
- Organização das informações do atendimento.

## 🧠 Prompt utilizado

O prompt completo está disponível em [prompt.md](prompt.md).

## 🧪 Testes realizados

O assistente foi planejado para ser testado em situações comuns de vendas, como:

- Cliente procurando notebook com orçamento limitado.
- Cliente questionando o preço de um produto.
- Criação de apresentação de produto.
- Recuperação de clientes interessados.
- Organização das informações de atendimento.

## 📸 Evidências

Após realizar os testes, adicionar as capturas de tela:

- `prompt-inicial`
- `teste-atendimento`
- `teste-objecao`
- `teste-followup`

## 💡 Aprendizados e conclusões

Com esse projeto, pude entender melhor como a IA pode ajudar no atendimento ao cliente e facilitar o trabalho de vendedores.

Também aprendi que um prompt bem organizado faz diferença na qualidade das respostas e que é importante testar o assistente em situações reais.

## ✅ Resultado final

O projeto apresenta a proposta de um assistente de vendas capaz de apoiar atendimentos, criar argumentos comerciais e sugerir mensagens para clientes.

Os testes e as capturas de tela servirão para demonstrar as funcionalidades que realmente foram validadas.
